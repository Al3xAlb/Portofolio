# Alex Alb — Graphic Design Portfolio

The portfolio of Alex Alb, showcasing colorful graphic design, illustration,
editorial work, visual identities, and poster projects.

The site pairs an airy, editorial layout with expressive artwork. Large project
images lead the experience, supported by simple navigation and concise project
details.

## Explore

- **Work** — Browse selected projects and open each one for more details and
  imagery.
- **About** — Learn about Alex, selected clients, contact details, and links.
- **Events** — Explore event galleries, including private galleries available
  with an access key.
- **Contact** — Send a message through the contact form.

## Visual direction

The design keeps the focus on the artwork: an uncluttered white background,
bold imagery, generous space, and clear typography create a clean editorial
feel.
